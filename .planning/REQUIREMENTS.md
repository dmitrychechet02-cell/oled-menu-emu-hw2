# Requirements

## Модуль 2

- [x] PIPE-01: GSD Core доступен; есть PROJECT, ROADMAP, STATE и планы фаз.
- [x] PIPE-02: архитектура и security checklist связаны с проектом.
- [x] MEM-01: агент восстанавливает STATE и последнюю запись журнала без всей истории.
- [x] HOOK-01: быстрые команды и автоматический чекпойнт перед compact в Claude Code.
- [x] CTX-01: приложены реальные снимки usage до и после compact одной сессии.
- [x] DISC-01: пользователь выбрал задачу и согласовал ограничения и поведение графика.

## График температуры — следующая фаза, реализация ещё не выполнена

- [ ] GRAPH-01: пункт «График» / “Graph” в главном меню, BACK возвращает в меню.
- [ ] GRAPH-02: последние 64 замера, интервал 1000 мс; сбор идёт и вне экрана графика.
- [ ] GRAPH-03: автоподбор Y, текущая температура, корректные 0/1/64 точки и плоский ряд.
- [ ] GRAPH-04: фиксированная RAM, целые числа, без libc и динамического выделения памяти.
- [ ] GRAPH-05: unit на историю/шкалу/время, e2e RU/EN и возврат, браузерная проверка.
