# Roadmap

## Overview

Модуль 2 оформляет цикл разработки для существующего эмулятора. Следующий
вертикальный срез — график температуры. Старый бэклог остаётся в docs/plan.md.

- [x] **Phase 1: Агентный пайплайн** — окружение, память, команды, Discovery и доказательства.

## Phase Details

### Phase 1: Агентный пайплайн

**Goal:** проверяющий воспроизводит команды и видит доказательства каждого пункта ДЗ.
**Depends on:** Nothing
**Requirements:** PIPE-01, PIPE-02, MEM-01, HOOK-01, CTX-01, DISC-01
**Success Criteria:**
1. GSD CLI читает roadmap; doctor и тесты hooks проходят.
2. Новая сессия получает актуальное состояние и последнюю запись памяти.
3. README содержит результаты, ограничения и два реальных снимка usage.

Plans:
- [x] 01-01-PLAN.md — настройка и проверка переносимой памяти и GSD.
- [x] 01-02-PLAN.md — пользовательская проверка compact и снимки usage.

### Phase 2: График температуры

**Goal:** пользователь видит тенденцию температуры за последнюю минуту.
**Depends on:** Phase 1
**Requirements:** GRAPH-01, GRAPH-02, GRAPH-03, GRAPH-04, GRAPH-05
**Success Criteria:**
1. Отдельный экран открывается и закрывается, RU/EN согласованы.
2. Буфер не превышает 64 замера; равные значения не приводят к делению на ноль.
3. C lint, unit, e2e и браузерная проверка проходят.

Plans:
- [ ] 02-01-PLAN.md — кольцевая история, экран, unit/e2e и визуальная проверка.
