# Discovery: график температуры

**Дата:** 2026-10-22. **Статус:** поведение первой версии согласовано в чате.
Формат: ручной Discovery по структуре GSD для существующего проекта.

## Задача и пользователь

Пользователь эмулятора хочет видеть изменение температуры за последнюю минуту,
не подключая железо. Пользователь выбрал именно эту задачу из текущего docs/plan.md.

## Согласованные ответы

1. Задача: «График температуры из текущего плана» — ответ пользователя.
2. Предложены отдельный пункт «График» / “Graph”, 64 последних замера,
   1 замер/с, шкала Y автоматически, текущее значение, BACK, RAM и очистка
   при перезапуске. Ответ пользователя: «Да, принять эти требования».

## Технические решения в пределах согласованного поведения

- Кольцевой буфер из 64 int16_t: 128 байт данных плюс счётчики; единица температуры
  должна совпадать с текущим источником sensors_update, уточнить перед реализацией.
- История собирается в app_tick независимо от текущего экрана, включая автосон;
  перезапуск очищает её. Flash и отдельный режим записи не нужны.
- Большой elapsed_ms не порождает 64 одинаковых фиктивных замера: добавить один
  актуальный замер и сохранить остаток периода. Проверить это unit-тестом.
- Данные 0/1 точка: пустая область/одна точка; одинаковые значения — линия по центру.
- Минимум/максимум и преобразование Y — int32_t для промежуточных вычислений;
  клиппинг в пределах области графика, заголовок меню не затирать.
- Размещение подписей выбрать при реализации по читаемости на 128×64.

## Критерии приёмки

- GRAPH-01…05 из REQUIREMENTS.md связаны с фазой 2.
- Unit: пустая история, 1/64/65 замеров, порядок после wrap, равные и отрицательные
  значения, границы int16_t, интервалы 999/1000 мс и большой elapsed_ms.
- E2E: открыть экран кнопками, дождаться данных, переключить язык, проверить BACK;
  не полагаться только на сравнение скриншота.
- Готово после lint, unit, e2e, проверки консоли и изображения через check-ui.

## Не входит

Реальный датчик, flash, экспорт CSV, выбор длительности, масштабирование кнопками,
новая иконка и переработка движка меню. Открытых продуктовых вопросов для MVP нет.
