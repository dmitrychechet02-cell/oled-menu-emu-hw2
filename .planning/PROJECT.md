# OLED Menu Emulator — агентный цикл разработки

## What This Is

Существующий эмулятор OLED SSD1309 128×64: ядро C11 без libc, WebAssembly,
интерфейс на JS, перенос на MCU через HAL. Модуль 2 добавляет управляемый цикл
Discovery → требования → план → реализация → проверки → память → проверка человеком.

## Core Value

Проверять поведение настоящего C-меню в браузере до переноса на плату.

## Requirements

### Validated

- ✓ C11 freestanding, framebuffer 1024 байта, шрифт RU/EN и движок меню.
- ✓ WASM-эмулятор, unit и e2e, защитные хуки, инструкции и журнал памяти.

### Active

- [x] Воспроизводимый агентный цикл и доказательства для модуля 2 (2026-10-22).
- [ ] Следующая продуктовая фаза: экран истории температуры за 64 замера.

### Out of Scope

- Часы, крупный шрифт и flash/CRC остаются в docs/plan.md, вне текущего цикла.
- Публикация, push, физическая плата, внешняя БД памяти и облачные API.

## Context

Discovery выполнен в чате 2026-10-22: пользователь выбрал график температуры
и подтвердил предложенное поведение; см. phases/02-temperature-graph/02-CONTEXT.md.
Это адаптация GSD для существующего проекта, выполненная текущим агентом вручную.
Команда $gsd-new-project целиком не запускалась; её автоматические исследования
и независимая проверка плана не заявляются выполненными.

## Constraints

- C11 без libc, float и сторонних библиотек ядра; строки через tr(STR_*), RU/EN вместе.
- Не менять секреты, lock-файлы и сгенерированные шрифты вручную.
- Ветки feat/* или fix/*, комментарии и Conventional Commits на русском.
- Готово: C lint, unit с sanitizer и Playwright; на Windows — существующие npm-обёртки.
