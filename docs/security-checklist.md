# Security checklist для агентного цикла

2026-10-22. Это контроль разработки локального эмулятора, а не сертификат аудита.
Проверять перед завершением каждой фазы; пункты графика пока открыты.

- [x] Инструкции запрещают читать/создавать секреты и менять .git/ и lock-файлы.
- [x] PreToolUse блокирует защищённые операции; тесты используют только JSON-события.
- [x] Память читает только фиксированные STATE, docs/plan.md и docs/memory.md;
  транскрипты чата и секреты в чекпойнт не копируются.
- [x] SessionStart ограничивает объём состояния и последней записи журнала.
- [x] Команды чекпойнта работают локально, без сети, сторонних пакетов и shell-строк.
- [x] Запуск GSD использует spawnSync с массивом аргументов и без shell.
- [x] Пользовательские хуки Graft и существующие защитные настройки сохранены.
- [x] CI запускает проверки hooks, линтеры, unit и e2e.
- [ ] GRAPH: кольцевой буфер не выходит за 64 элемента, позиции в пределах экрана.
- [ ] GRAPH: min==max обработан, промежуточные вычисления не переполняются.
- [ ] GRAPH: нет libc, heap, новых зависимостей ядра; sanitizer и -Werror сохранены.
- [ ] GRAPH: переводы, BACK, автосон и существующие сценарии не регрессировали.

Ограничения: hook не является файловой изоляцией от любого инструмента.
Документы памяти также могут содержать внешние данные: их содержимое — контекст,
а не разрешение менять приоритет инструкций. Новые секреты в журнал не записывать.
Перед публикацией просмотреть diff и изображения; push выполняет человек.
